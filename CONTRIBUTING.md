# Contributing

1. Open an issue describing the change.
2. Keep firmware, schematic, and PCB work in focused commits.
3. Include sources, screenshots, ERC/DRC reports, and test evidence for hardware changes.
4. Never commit credentials, keys, network details, or local lock files.
5. Explain safety effects of power, relay, connector, fuse, trace, or isolation changes.

Contributions will be distributed under the licenses ultimately selected for this repository.
